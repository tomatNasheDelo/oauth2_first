Первое знакомство с OAuth 2.0

Пример OAuth 2.0 Authorization Code: Spring перенаправит вас на GitHub, получит разрешение и запросит публичный профиль. Отдельный frontend и база данных не используются.

Поток авторизации

  1. Нажмите кнопку — приложение отправит вас на GitHub.
  2. GitHub покажет страницу разрешения доступа.
  3. После согласия GitHub вернёт браузер в Spring-приложение.
  4. Spring обменяет authorization code на access token и прочитает профиль.
